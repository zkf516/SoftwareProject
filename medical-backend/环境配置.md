# 环境配置说明

本项目推荐使用 Python 虚拟环境或 Conda 环境进行开发和部署。

## 1. 使用 venv 创建虚拟环境

```powershell
cd medical-backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

## 2. 使用 Conda 创建环境

```powershell
conda create -n medical-env python=3.10
conda activate medical-env
pip install -r requirements.txt
# 或使用 conda 安装部分包
conda install pandas openpyxl flask
```

## 3. 启动服务

```powershell
python app.py
```

## 4. 依赖说明
- flask：Web 框架
- pandas：数据处理
- openpyxl：Excel 读取

## 5. 目录结构
```
medical-backend/
├─ app.py                # 主后端入口
├─ requirements.txt      # 依赖包
├─ excel_data/           # 存放 Excel 文件
│    ├─ disease.xlsx
│    └─ data.xlsx
└─ utils/
     └─ excel_reader.py  # Excel 读取工具
```

## 6. 常见问题
- 如遇缺少依赖，请使用 `pip install 包名` 或 `conda install 包名` 安装。
- 开发环境建议使用虚拟环境，避免依赖冲突。
